# ساخت APK دفتر هوشمند (بدون Android Studio)

1. در github.com یک مخزن (Repository) جدید بساز؛ خصوصی هم مشکلی ندارد.
2. محتویات این پوشه را در مخزن آپلود کن.
   - کامپیوتر: همهٔ فایل‌ها و پوشهٔ `.github` را بکش و رها کن.
   - گوشی: فایل‌های ریشه را آپلود کن، سپس `build-apk.yml` را باز کن، Edit بزن و نام آن را به `.github/workflows/build-apk.yml` تغییر بده.
3. تب Actions ← Build APK ← Run workflow. حدود ۵ تا ۸ دقیقه صبر کن.
4. وقتی سبز شد، از پایین صفحهٔ همان اجرا، فایل `daftar-hooshmand-apk` را دانلود و از حالت زیپ خارج کن؛ داخلش `app-debug.apk` است.
5. روی گوشی نصب کن (اجازهٔ «نصب از منابع ناشناس» لازم است).

نکته‌ها
- اطلاعات اپ نصب‌شده جدا از نسخهٔ مرورگر است. قبل از رفتن، در نسخهٔ قبلی پشتیبان JSON بگیر و در اپ جدید وارد کن.
- خروجی CSV/TXT/JSON از طریق منوی اشتراک‌گذاری اندروید ذخیره می‌شود.
- چاپ و «ذخیره به‌عنوان PDF از طریق چاپ» در APK پشتیبانی نمی‌شود.
- اگر Actions خطا داد، متن خطای آخرین مرحله را برایم بفرست.
