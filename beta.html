ذخیره‌سازی و انتقال دستگاه

ذخیرهٔ خودکار روی همین مرورگر/دستگاه است. برای انتقال، ابتدا از نسخهٔ قبلی پشتیبان JSON بگیر و اینجا آن را بازیابی کن. پاک‌کردن داده‌های مرورگر ممکن است اطلاعات محلی را حذف کند.

انتقال و ادغام بین دستگاه‌ها

برای ادغام، از دستگاه اول پشتیبان JSON بگیر و اینجا وارد کن. موارد موجود با شناسهٔ یکسان دوباره ثبت نمی‌شوند؛ تعارض‌ها گزارش می‌شوند و فایل فعلی قبل از ادغام پشتیبان می‌شود. این قابلیت انتقال دستی است، نه همگام‌سازی خودکار ابری.

هیچ داده‌ای حذف یا جایگزین نمی‌شود؛ تنظیمات محلی دستگاه فعلی حفظ می‌شوند.

همگام‌سازی بین دستگاه‌ها (سرور شخصی)

برای همگام‌سازی زنده، یک سرور سازگار لازم است. بستهٔ نسخهٔ ۲۱ یک سرور همگام‌سازی با توکن‌های جدا برای هر حساب و مخزن مستقل هر حساب دارد؛ فقط روی HTTPS یا پشت reverse proxy امن میزبانی شود. تا وقتی سرور تنظیم نشده، انتقال فایل JSON همچنان گزینهٔ اصلی است.

توکن در داده‌های برنامه ذخیره نمی‌شود و پس از بارگذاری مجدد باید دوباره وارد شود. همگام‌سازی بدون سرور سازگار فعال نیست.

قرارداد سرور در فایل README و sync-server.js شرح داده شده است. سرور نمونه برای استفادهٔ شخصی است؛ برای هر حساب یک توکن مجزا در تنظیمات سرور تعریف می‌شود؛ داده‌ها هنگام ذخیره روی دیسک رمزگذاری می‌شوند، اما رمزگذاری سرتاسری بین دستگاه و سرور نیست. کلید را امن نگه دار و نسخهٔ پشتیبان خارج از سرور داشته باش.

شامل PDFهای اصلی

این بسته شامل داده‌های برنامه، دفترچه‌ها، فلش‌کارت‌ها، حاشیه‌های PDF و فایل‌های اصلی PDF موجود در حافظهٔ محلی است. قالب ZIP بدون فشرده‌سازی ساخته می‌شود تا روی مرورگرهای موبایل سبک‌تر و قابل‌بازیابی باشد؛ این گزینه رمزگذاری ندارد و برای اطلاعات خصوصی از خروجی رمزدار پایین استفاده کن. فایل اصلی PDF که در مخزن محلی پیدا نشود در گزارش بسته مشخص می‌شود.

برای انتقال کامل، از پشتیبان ZIP استفاده کن؛ JSON معمولی بایت‌های PDF را شامل نمی‌شود.
پشتیبان کامل رمزگذاری‌شدهAES-GCM-256

این خروجی، هم داده‌های برنامه و هم فایل‌های اصلی PDF را داخل یک بستهٔ رمزگذاری‌شده قرار می‌دهد. رمز فقط برای همین عملیات استفاده می‌شود و در برنامه ذخیره نخواهد شد. فایل‌های پشتیبان نسخه‌های ۲۳، ۲۴ و ۲۵ نیز همچنان قابل بازیابی هستند.

رمز را در مدیر گذرواژه یا جای امن دیگری نگه دار. فراموشی رمز به معنی غیرقابل‌بازیابی شدن فایل است. برای بازیابی همین فایل رمز را در کادر اول وارد کن.

همگام‌سازی رمزگذاری‌شدهٔ سرتاسری

رمزگذاری در دستگاه

محتوا پیش از ارسال در مرورگر با AES‑GCM‑256 رمزگذاری می‌شود. سرور نسخهٔ ۲۳ فقط متن رمز‌شده را دریافت می‌کند و رمز عبور همگام‌سازی در برنامه ذخیره نمی‌شود. برای هر دو دستگاه از یک رمز طولانی و یک حساب سرور استفاده کن؛ فراموش‌کردن رمز یعنی دادهٔ ابری قابل رمزگشایی نیست.

همگام‌سازی تا زمان میزبانی سرور روی HTTPS فعال نیست. توکن و رمز همگام‌سازی در حافظهٔ فرم می‌مانند و در state ذخیره نمی‌شوند.

سرور نمونه برای استفادهٔ شخصی/آزمایشی است و قبل از استفادهٔ واقعی باید پشت HTTPS، با توکن تصادفی جدا برای هر حساب، فایل محیطی محرمانه، پشتیبان سرور و بازبینی امنیتی میزبانی شود. رمزگذاری سرتاسری در نسخهٔ ۲۳ روی محتوای JSON است؛ فایل‌های PDF باینری فقط در پشتیبان ZIP کامل قرار می‌گیرند و در کانال E2EE فعلی همگام نمی‌شوند.

پشتیبان رمزگذاری‌شده و حریم خصوصی

پشتیبان JSON را با رمز عبور و AES‑GCM رمزگذاری کن. از رمز طولانی و منحصربه‌فرد استفاده کن؛ اگر رمز را فراموش کنی، فایل رمزگذاری‌شده قابل بازیابی نیست. فایل‌های PDF اصلی باید جداگانه از کتابخانهٔ PDF دانلود شوند.

داده‌ها به‌صورت محلی ذخیره می‌شوند؛ همگام‌سازی ابری فقط پس از تنظیم سرور شخصی و توکن فعال خواهد شد.
پشتیبان تأییدپذیر با SHA-256بررسی خرابی ناخواسته

این قالب برای تشخیص تغییر یا خرابی تصادفی فایل است؛ امضای دیجیتال یا تضمین اصالت فرستنده نیست. برای رمزگذاری، از پشتیبان رمزدار استفاده کن.

نقطهٔ بازیابی محلی

در مرورگرهای پشتیبانی‌شده، برنامه گاهی نسخه‌ای از داده‌های قبلی را در حافظهٔ داخلی نگه می‌دارد. این نسخه جای پشتیبان JSON را نمی‌گیرد. مرورگر ممکن است مجوز نگهداری پایدار را نپذیرد.
